# Mohan Atluri — Professional Resume Website

A single-page resume website for **Mohan Atluri, PE, PTOE, RSP1**, built for GitHub Pages.

## Live URL (after setup)

Once published, the site will be available at:

**https://mohan-prasant-atluri.github.io/resume/**

(Replace `resume` with your repository name if different.)

## Project Structure

```
mohan-resume-website/
├── index.html          # Main page
├── css/style.css       # Styles
├── js/main.js          # Navigation & interactions
├── assets/profile.jpg  # Profile photo
└── README.md
```

## Local Preview

Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080
